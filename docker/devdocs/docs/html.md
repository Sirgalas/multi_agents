# HTML5 & Web Standards Guidelines

- **Semantic Elements**: Structure documents using header, nav, main, article, section, footer.
- **Accessibility (a11y)**: WAI-ARIA roles, landmark regions, and descriptive aria-label attributes where appropriate.
- **Form Controls**: Explicitly connect labels and inputs with for/id pairs; use semantic types (email, tel, number).
- **Viewport & Meta**: Ensure proper mobile responsive meta tag: <meta name="viewport" content="width=device-width, initial-scale=1.0">.
- **SEO & Social**: Include comprehensive title, meta descriptions, Open Graph, and Twitter card tags.
